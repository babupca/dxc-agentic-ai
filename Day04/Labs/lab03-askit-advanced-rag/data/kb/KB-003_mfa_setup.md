# Multi-Factor Authentication (MFA)

MFA is mandatory for all accounts. Use the Orbit Authenticator app.
New phone? Before wiping the old phone, go to https://mfa.orbitcorp.example and move MFA to the new device.
Lost phone with MFA: call the helpdesk. After identity verification by video call, a temporary access code valid for 24 hours is issued.
Never approve an MFA prompt you did not start — report it as a security incident.
