# Shared Mailbox Access

Access to a shared mailbox must be approved by the mailbox owner. Raise an Access Request naming the mailbox and owner.
After approval, access appears in Outlook within 2 hours; restart Outlook if it does not.
Send-as permission is separate and must be requested explicitly.
