# Escalation Policy

L1 helpdesk handles tickets first. Escalate to L2 when: not resolved within 50% of the SLA, needs admin/server access, or the same issue affects 3+ users.
Escalate to the Security team immediately for: suspected phishing clicks, unknown MFA prompts, lost devices, malware alerts.
Tickets from VIP users are always handled by a human agent — never auto-closed.
